# Generic Skills

Reusable agent skills that are independent of a particular platform or vendor.

| Skill                                             | What it does                                                                                            |
| ------------------------------------------------- | ------------------------------------------------------------------------------------------------------- |
| [chronicle-protocol](chronicle-protocol/SKILL.md) | Writes a project checkpoint on "Chronicle" and guides resuming from it across sessions and platforms.   |
| [demo-director](demo-director/SKILL.md)           | Plans, scripts, rehearses, records, and finishes software demos with approval gates and quality checks. |

Add each skill in its own `<skill-name>/` folder with a `SKILL.md` entry point and any supporting files alongside it. Keep skill names unique across categories.

See the [repository README](../../README.md) for the catalog and installation instructions.
