# Lessons retained from the source demonstrations

These are historical examples, not a requirement to access their original sessions
or files. The skill is self-contained and must not inherit their machine details.

## Census conference demo

Reference session: `2c353b9c-6fa7-408c-bbaf-12d6b90fc5ad`, titled
**Census conference demo**.

- Began with an approved five-minute script; later versions tightened to 3:55.
  The user praised polish without cheesy or over-produced treatment.
- The emphasis shifted from Census particulars to natural-language interaction,
  statistical and geographic tools, and a repeatable demographic workflow.
- Replacing a repeated statistics view with a substantive workflow improved the
  ending. The key lesson is to advance the story, not revisit a weaker result.
- An eight-second map pause felt too long and became three seconds.
- Light/dark pairs shared content and timing. A real Chromium/Playwright app replayed
  captured genuine SSE responses, with input/order/content checks. It was not an
  HTML screenshot recreation, and should not be described as an unprepared live run.
- Live report evidence included actual report shape, data vintage, geographic count,
  and values; those checks were separate from styling and timeline staging.
- Boundary retrieval and statistical tools had different responsibilities. Narration
  avoided overstating MCP or implying a different model backend from what was configured.
- A database/port problem was investigated without recreating or deleting the database.
- Delivering full disk paths plus Markdown/Word scripts solved download and handoff needs.

## Native AI/GIS application closer

Reference: this demo's **From analysis to application** script, Draft 5, and
`federal-ai-gis-demo-application-v2.mp4` (2:30, silent 1080p30).

- The first accurate analysis/report video lacked a strong enough closing payoff.
  The approved recut devoted much more time to a real generated application and its
  independently working browser preview.
- Genuine native desktop capture used smooth minimum-jerk pointer motion; cursor
  teleporting was explicitly rejected.
- The user widened chat for readability. That width stayed fixed. When no real
  hide-chat control was available, honest editorial reframing replaced a proposed
  collapse; the UI was not counterfeited.
- Generated UI needed actual repairs: preserved map-layer lifecycle, supported map
  controls, managed selection highlighting, correct hit-test attributes, and mobile
  padding so a detail sheet did not cover the selected marker.
- Independent checks compared six records with retained responses and tested real
  map hits, filters, selection, source notes, and absence of desktop-only auth globals.
  Counts alone were insufficient.
- The Mac locked mid-work. Accessibility returned misleading application-level data,
  and the old window ID was unavailable. The process stopped for the user to unlock,
  then exact window-role/identity guards and renewed preflight prevented a bad take.
- A temporary bounded sleep inhibitor protected recording from idle sleep, not manual
  locking. It was stopped after capture; no global security or power policy changed.
- A browser address-bar tooltip spoiled a clean hold; a short new intro/ending pickup
  fixed it without discarding the successful interaction take.
- Native/browser clip timebases differed; normalized decoded concat avoided bad timestamps.
- Final delivery was 4,500 frames, with a two-second genuine hold, full-frame name
  exclusion audit, source/claim evidence, and preserved earlier versions.
- An unavailable built-in export menu was not fabricated. The portable app ran in
  a **local preview**; actual hosting and access controls remained separate.

## Generalize, do not copy

Do not hardcode the historical OS, application, PIDs, window IDs, geometry, ports,
data identities, tool-call IDs, claims, silent audio, runtime, or output style.
Carry forward approval gates, honesty, observable outcomes, platform routing,
short rehearsal, smooth motion, safe recovery, and exact deliverable verification.
